Java 11 Features
1. Local-Variable Syntax for Lambda Parameters
- Allows var in lambda parameters for consistency and annotations.
(var x, var y) -> x + y

Useful when adding annotations
(@NotNull var x, @NotNull var y) -> x + y

Why it matters:
- Improves readability
- Enables parameter annotations
------------------------

2. New String Methods
" ".isBlank();                 // true
"Java\n11".lines().count();    // 2
" Java ".strip();              // "Java"
"Ja".repeat(3);                 // "JaJaJa"

Key methods:
1. isBlank()
2. strip(), stripLeading(), stripTrailing()
3. lines()
4. repeat(int)
------------------------

3. New HTTP Client (Standardized)
Replaces legacy HttpURLConnection.

HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("https://example.com"))
        .GET()
        .build();

HttpResponse<String> response =
        client.send(request, HttpResponse.BodyHandlers.ofString());
 
Features:
- HTTP/1.1 & HTTP/2
- Async support
- Cleaner API

Java 17 features:
1. Sealed Classes (Finalized)
Control which classes or interfaces can extend or implement a class.

public sealed class Shape permits Circle, Rectangle {
}
------------------------
2. Pattern Matching for switch (Preview)
Simplifies logic by matching types directly in switch.

Example:
switch (obj) {
    case Integer i -> System.out.println(i + 1);
    case String s  -> System.out.println(s.length());
    default -> System.out.println("Unknown");
}
------------------------
3. Pattern Matching for instanceof (Finalized)
if (obj instanceof String s) {
    System.out.println(s.toLowerCase());
}
------------------------
