What is Array
Array fixed size data structure that stores elements of the same type in contiguous memory.

Advantage:
1. We can represent huge number of values by using single variable. 
So that readability of code will be improved 

Disadvantages
1. Array are fixed in size. There is no chance of increasing or decreasing based on our requiremen. So while using array we should compulsary know size of array. Which is not always possible.
2. Array can hold only homogeneous data type elements.
------------------------------------------------------
Array Creation and Initilization:
Every array in java is object only. Hence we can create array using new operator.
At the time of creation we must provide size.
e.g. int[] a = new int[5]; or int[] a = {10,20,30,40,50};  
int[] x = new int[]; invalid
int[] x = new int[6]; valid
int[] x = new int[0]; valid
int[] x = new int[-3]; invalid. java.lang.NegativeArraySizeException
int[] x = new int['a'];// valid 97

Accessing array element
int[] numbers = {10,20,30,40,50};
System.out.println(numbers[1]);
------------------------------------------------------
Looping through an Array
int[] numbers = {10,20,30,40,50};
System.out.println(numbers[1]);
for (int i=0; i<numbers.length; i++) {
  System.out.println(numbers[i]);            
}
OR
for (int num : numbers) {
  System.out.println(num);
}

Common Array methods Via Arrays class
1. toStirng()//Convert array to readable string
Arrays.toString();

2. sort() //Sorts array in ascending order
Arrays.sort(arr);

3. equals()// compares two arrays
Arrays.equals(a,b)

4. fill()//Fills array with specific values
int[] arr = new int[5];
Array.fills(arr,10)
o/p: [10,10,10,10,10];

5. copyOf()// copies array to new one
int[] newArr = Arrays.copyOf(arr,3);

6.copyOfRange()//copies a specific range
Arrays.copyOfRange(arr,1,4);

7. asList()
String[] arr = {"A","B","C"};
List<String> list = Arrays.asList(arr);
