Q1. What is a Thread?
Ans: 
- A thread is lightweight sub process that allows a java program to perform multiple tasks concurrently (multithreading).
- Multiple threads share the same memory space of a process but execute tasks independently.
----------------------------------------------------------------------------------------------------
Q2. What is multithreding?
Ans: 
- Multithreading is a programming technique where multiple threads run concurrently within a single program to perform     different tasks at the same time. 
- It improves CPU utilization and performance.
----------------------------------------------------------------------------------------------------
Q3. Ways to create a thread in Java?
Ans:
There are two ways to create thread in java.
1. Extending thread class
class DemoThread extends Thread {
    public void run() {
        System.out.println("Thread Running..");
    }
}

class MyThread {
    public static void main(String[] args) {
        DemoThread t = new DemoThread();
        t.start();
    }
}

2. Implementing Runnable
class DemoThread implements Runnable {
    public void run() {
        System.out.println("Thread running..");
    }
}

class MyThread {
    public static void main(String[] args) {
        Thread t = new Thread(new DemoThread());
        t.start();
    }
}

Runnable is preferred because:
- It supports multiple inheritance.
- Better Design.
- Separation of tasks and Thread.

Q4. What is a Thread Life Cycle?
Ans:
During execution, a thread goes through various stages such as:
NEW – Thread is created but not started
RUNNABLE – Thread is ready or running
BLOCKED – Waiting to acquire a monitor lock
WAITING – Waiting indefinitely for another thread
TIMED_WAITING – Waiting for a specific time period
TERMINATED – Thread execution completed

Q5. Important thread methods?
Ans:
start(): starts a new thread
run(): Task Executed
sleep(): pause thread
join(): wait for thread to finish
yield(): Gives chance to other thread
interrupts(): Interrupt thread

Q6. Thread Priority?
Ans:
Range: 1 (MIN) - 10(MAX)
Default: 5
Setting priority to thread:
t.setPriority(Thread.MAX_PRIORITY);
